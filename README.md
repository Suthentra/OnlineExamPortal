# Online Examination Portal

A full-stack web application for conducting online exams with admin panel and student interface.

# Features

## Student Features
- Register and Login with JWT authentication
- View available published exams
- Take timed exams with real-time countdown timer
- Navigate between questions with question palette
- Auto-save answers
- Auto-submit on timer expiry
- View results with score, percentage, and pass/fail status

## Admin Features
- Secure login with role-based access
- Create, Read, Update, Delete exams
- Add, Edit, Delete questions
- Publish exams
- View student performance and results

# Tech Stack
 
 Backend - .NET 8 
 Frontend - Angular 17 
 Database - SQL Server 
 Authentication - JWT Bearer Token 
 API Documentation - Swagger 
 Styling - Bootstrap 5, CSS3
